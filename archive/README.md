## Archive

This directory contains historical code that is retained for reference but is
not part of the canonical public API for this repository.

- `legacy/graph/`
- `legacy/qs/`
- `legacy/qw/`

If you are reading the repository for the first time, start with the current
modules in the repository root instead:

- `graph/`
- `qs/`
- `qw/`
- `cw/`

Do not start with the files in `legacy/`. They are preserved because they show
earlier implementations used during research iteration, but they are not the
recommended entry point for public readers.

- `legacy/graph/old_graph.py`
  Earlier graph-processing implementation kept for historical comparison.
- `legacy/qs/old_qs.py`
  Earlier quantum-search implementation retained as a reference point.
- `legacy/qw/old_qw.py`
  Earlier quantum-walk implementation retained as a reference point.
