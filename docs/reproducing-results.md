# Reproducing Results

This repository is a research companion codebase, not a full thesis
reproduction package.

## What This Repo Does Provide

- Core graph-generation code
- Core unitary and non-unitary search/walk routines
- Minimal examples
- Smoke tests for packaging and basic functionality
- Archived historical implementations for reference

## What This Repo Does Not Guarantee

- A one-command reproduction of all thesis figures, tables, and experiments
- Full research environment capture from the original development period
- A polished general-purpose public library API

## Recommended Reading Order

1. `README.md`
2. `docs/api-map.md`
3. `docs/workflows.md`
4. `examples/basic_usage.py`
5. `graph/`, `qs/`, and `qw/`

If you need historical context, then consult `archive/legacy/`.
